🎯 Formål

Denne side er skabt ud fra én simpel idé: politikere bør holdes ansvarlige for hvad de rent faktisk stemmer — ikke kun hvad de siger i medierne eller på valgkampagne.

Alt for ofte kan der være forskel på en politikers offentlige udmeldinger og deres adfærd i Folketingssalen. Med denne database kan du selv tjekke fakta.

Data dækker den fulde valgperiode fra 1. november 2022 og inkluderer alle afstemningstyper: endelige vedtagelser, ændringsforslag og udvalgsindstillinger.

📚 Kilder og teknologi

  • Folketingets Åbne Data API (oda.ft.dk)

    Alle afstemninger, stemmer og politikerdata hentes direkte fra Folketingets officielle OData API — åbent og gratis tilgængeligt.

  • Anthropic Claude API

    AI-kategorisering af lovforslag og beslutningsforslag i 19 politiske emner, baseret på titler og resuméer.

  • Python · Flask · SQLite

    Backend bygget med Python og Flask, data gemt i SQLite. Frontend med Tailwind CSS.
